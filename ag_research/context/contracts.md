# System Contracts

## Module A: Infra (Microservices + Deployment)
- **Input Contract**: 
  - Simulated traffic from Load Generator.
  - Remediation commands (e.g., restart, scale) from Module D.
- **Output Contract**: 
  - Emits raw metrics (exposed endpoints).
  - Emits raw logs (stdout/stderr).
  - Emits raw traces (OTLP).

## Module B: Observability (Metrics / Logs / Traces)
- **Input Contract**: 
  - Raw observability data generated by Module A.
- **Output Contract**: 
  - Structured, queryable metrics (e.g., PromQL).
  - Structured, queryable logs (e.g., LogQL).
  - Structured traces with span details.

## Module C: Detection (Anomaly Detection)
- **Input Contract**: 
  - Real-time structured metrics stream from Module B.
- **Output Contract**: 
  - Instant anomaly alert payload containing: `timestamp`, `affected_service`, `metric_deviated`.

## Module D: RCA + Remediation
- **Input Contract**: 
  - Anomaly alert payload from Module C.
  - Query access to logs and traces from Module B to context-gather and correlate.
- **Output Contract**: 
  - Root cause decision payload: `failing_component`, `reason`.
  - Action execution payload sent to Module A: `action_type`, `target`.

## Module E: Dashboard (Visualization)
- **Input Contract**: 
  - Query endpoints for metrics, logs, and traces from Module B.
  - Real-time alert feed from Module C.
  - RCA and Remediation audit logs from Module D.
- **Output Contract**: 
  - Unified UI reflecting current system state, detected anomalies, root causes found, and actions taken.
